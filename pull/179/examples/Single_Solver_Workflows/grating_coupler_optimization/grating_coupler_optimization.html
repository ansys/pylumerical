Grating Coupler: Optimization#

Given a grating coupler design, this example demonstrates how to optimize the fiber position for improved coupling efficiency.

This example is the second part of the grating-coupler workflow:

  • Create a grating coupler: set up the base simulation and run it.

  • Optimize the grating coupler: improve the fiber position for better coupling efficiency.

  • Extract S-parameters: export S-parameters to Interconnect.

  • Lumerical FDTD and Zemax Interconnect: export the field to ZBF for import into Zemax.

This example demonstrates how to set up a SciPy optimization with a small number of variables.

Prerequisites#

A valid FDTD license is required.

Import required modules#

2import numpy as np
3import scipy as sp

4import ansys.lumerical.core as lumapi

Assign key parameters#

[ ]:

 5show_GUI = True
 6# The `grating_coupler.fsp` file can be obtained by following the previous steps in the grating coupler workflow.
 7load_file_name = "your/path/to/grating_coupler.fsp"
 8save_file_name = "your/path/to/grating_coupler_optimized.fsp"
 9
10# Unit conversion factors
11um_to_m = 1e-6
12m_to_um = 1e6
13
14# Optimization variable: fiber x-position `fiber_x_pos`
15fiber_x0 = [5.0 * um_to_m]
16fiber_x_bounds = [(1.5 * um_to_m, 5.0 * um_to_m)]
17
18# Optimization target: maximize transmission at the target wavelength `lambda_0`
19lambda_0 = 1.55 * um_to_m
20
21# User-defined constant
22sio2_tox_offset = 0.65 * um_to_m

Set up FDTD simulation environment#

Load the grating coupler .fsp file. It can be obtained by following the previous steps in the grating coupler workflow.

[ ]:

23# Load the project file.
24fdtd = lumapi.FDTD(hide=not show_GUI)
25fdtd.load(load_file_name)
26
27# Use the coarsest mesh accuracy for faster optimization
28fdtd.switchtolayout()
29fdtd.setnamed("FDTD", "mesh accuracy", 1)
30
31# Capture the initial fiber and TOX positions and parameters.
32fiber_y_pos = fdtd.getnamed("fiber", "y")
33fiber_z_pos = fdtd.getnamed("fiber", "z")
34fiber_theta = fdtd.getnamed("fiber::core", "rotation 1")
35fiber_core_diameter = fdtd.getnamed("fiber::core", "radius") * 2
36tox_zpos = fdtd.getnamed("SiO2 TOX", "z")
37
38# Calculate intermediate parameters and assign their values.
39port1_z_pos = tox_zpos + fiber_z_pos + sio2_tox_offset * np.cos(np.deg2rad(fiber_theta))
40port_offset = 4.0 * fiber_core_diameter * np.tan(np.deg2rad(fiber_theta))
41fdtd.setnamed("::model::FDTD::ports::port 1", "y", fiber_y_pos)
42fdtd.setnamed("::model::FDTD::ports::port 1", "z", port1_z_pos)
43fdtd.setnamed("::model::FDTD::ports::port 1", "theta", fiber_theta)
44fdtd.setnamed("::model::FDTD::ports::port 1", "rotation offset", port_offset)

Scipy optimization#

For a small number of variables (<=3), we recommend using SciPy as the optimizer. For a large number of variables, we recommend using lumopt2.

Here, we use the SciPy Powell method. To run the optimization, define:

  • an objective function that takes the parameters and returns a fitness value,

  • an initial guess for the variables, and

  • bounds that physically constrain the variables.

[ ]:

45# To optimize more variables, add them to `x0` and `bounds`, then unpack them here.
46fitness_history = []
47
48
49def objective(params: np.ndarray) -> float:
50    """Objective function for optimizing the fiber's x-position.
51
52    Args:
53        params (np.ndarray): Array containing the fiber x-position [fiber_x_pos].
54
55    Returns
56    -------
57        float: The negative transmission at the target wavelength.
58    """
59    # Step 1: Capture the current parameter (fiber x-position).
60    fiber_x_pos = float(params[0])
61
62    # Step 2: Apply the current parameter to the simulation layout.
63    # Fiber x-position
64    fdtd.switchtolayout()
65    fdtd.setnamed("fiber", "x", fiber_x_pos)
66    # Port 1 position
67    port1_x_pos = fiber_x_pos + sio2_tox_offset * np.sin(np.deg2rad(fiber_theta))
68    fdtd.setnamed("::model::FDTD::ports::port 1", "x", port1_x_pos)
69
70    # Step 3: Extract the merit function value (transmission at the target wavelength).
71    fdtd.run()
72    # Extract the wavelengths and transmission values from the simulation result.
73    transmission = fdtd.getresult("::model::FDTD::ports::port 2", "T")
74    wavelengths = np.asarray(transmission["lambda"]).squeeze()
75    values = np.abs(np.asarray(transmission["T"]).squeeze())
76    fitness = float(values[np.argmin(np.abs(wavelengths - lambda_0))])
77
78    # Append the current fitness to the history to track optimization progress.
79    fitness_history.append(fitness)
80
81    # The objective function must return a value to minimize, so return the negative fitness.
82    return -fitness

[ ]:

83# Run the optimization using SciPy's `minimize` function. This may take a while because it runs multiple simulations.
84result = sp.optimize.minimize(objective, fiber_x0, method="Powell", bounds=fiber_x_bounds)
85if not result.success:
86    raise RuntimeError(result.message)
87
88best_fiber_x_pos = result.x[0]
89print(f"Optimal fiber x: {best_fiber_x_pos * m_to_um:.3f} um; transmission: {-result.fun:.4f}")

Apply the optimization result to the simulation layout#

[ ]:

90best_port1_x_pos = best_fiber_x_pos + sio2_tox_offset * np.sin(np.deg2rad(fiber_theta))
91
92fdtd.switchtolayout()
93fdtd.setnamed("fiber", "x", best_fiber_x_pos)
94fdtd.setnamed("::model::FDTD::ports::port 1", "x", best_port1_x_pos)
95fdtd.save(save_file_name)

[ ]:

 96# Plot the optimization progress.
 97best_fitness = np.maximum.accumulate(fitness_history)
 98plt.plot(best_fitness)
 99plt.xlabel("Objective evaluation")
100plt.ylabel("Best transmission")
101plt.title(f"Fitness improvement: {best_fitness[0]:.4f} to {best_fitness[-1]:.4f} (+{best_fitness[-1] - best_fitness[0]:.4f})")
102plt.tight_layout()
103plt.show(block=False)
